============================================================
КАК ЗАПУСТИТЬ
============================================================
1. Положите Jarvis.exe в любую папку (рабочий стол, флешка — без разницы).
2. Двойной клик по файлу.
3. Перетащите видео или картинку в окно (или нажмите на область выбора файла).

Всё. Ничего доустанавливать не нужно: FFmpeg и yt-dlp уже находятся внутри exe.
Node.js, Python и отдельные кодеки не требуются.

Требования: Windows 10/11, 64-бит. .NET Framework 4.8 уже входит в Windows.
Права администратора не нужны. Конвертация полностью локальная.
Интернет нужен только для скачивания (TikTok, YouTube, Spotify и другие сайты).

Размер exe — около 60 МБ. При первом запуске FFmpeg (около 100 МБ)
и yt-dlp (около 24 МБ) распаковываются в %LOCALAPPDATA%\Video2Gif
за пару секунд. Повторно распаковываться не будут.

============================================================
ПЕРВЫЙ ЗАПУСК И SMARTSCREEN
============================================================
Файл не подписан платной цифровой подписью, поэтому Windows SmartScreen
может показать синее окно «Windows защитила ваш компьютер».
Нажмите «Подробнее» → «Выполнить в любом случае». Это нормально для
неподписанных программ, собранных вручную.

Некоторые антивирусы иногда ругаются на распакованный ffmpeg.exe.
Это оригинальная сборка FFmpeg essentials (gyan.dev), а не вирус.

Передать другому человеку можно просто один файл Jarvis.exe —
ничего дополнительно передавать не нужно.

============================================================
ВОЗМОЖНОСТИ
============================================================
- Любые форматы, которые читает FFmpeg: MP4, MKV, AVI, MOV, WebM, WMV,
  FLV, MPEG, TS/MTS, 3GP, OGV, GIF и другие.
- Картинки в GIF: PNG, JPG/JPEG, WEBP, BMP, TIFF, TGA, AVIF.
  Получается GIF из одного кадра с задержкой 0,1 с (10 кадров/с).
- Качественный GIF через палитру: palettegen + paletteuse, 2 прохода.
- Частота кадров по умолчанию 30/с, можно поставить от 1 до 60.
- Для видео: начало и длительность фрагмента, ширина, кадры в секунду.
- Для всех файлов: ширина, сглаживание
  (Байер / Sierra / без сглаживания; по умолчанию Sierra). Палитра — 256 цветов.
- Бесконечный цикл или один проигрыш.
- Быстрый режим — один проход вместо двух.
- Прогресс с процентами и кнопка «Отменить».
- Предпросмотр результата, «Сохранить GIF» и «Открыть».
- Скачивание TikTok без водяного знака: видео MP4 и фото-посты.
  Нужна только ссылка; файл сохраняется на диск и сразу открывается в программе.
- Скачивание с YouTube, SoundCloud, VK и тысяч других сайтов через yt-dlp:
  видео MP4 или музыка MP3, на выбор.
- Музыка по ссылке Spotify: трек, альбом или плейлист. Программа берёт
  название и исполнителя со страницы Spotify, ищет трек на YouTube
  (сверяет длительность, чтобы не попасть на клип или ремикс) и сохраняет
  MP3 или WAV на выбор. Это не прямое скачивание из Spotify: DRM там не обходится.
- Скачанные файлы и готовый GIF по умолчанию сохраняются на рабочий стол.
  Папку всегда можно изменить в окне сохранения.
- Тёмная тема включена по умолчанию; светлая — кнопкой в правом верхнем углу.
  Выбор запоминается.
- Перетаскивание файла на окно или на сам exe.
- Если передать путь к видео или картинке аргументом командной строки,
  файл сразу откроется.

============================================================
УПРАВЛЕНИЕ
============================================================
- Перетащить файл: в любое место окна.
- Нажать на верхнюю карточку: выбрать другой файл.
- «Другой файл»: заменить выбранный файл.
- «Сделать GIF»: запустить конвертацию.
- «Отменить»: остановить конвертацию (FFmpeg завершается сразу).
- «Сохранить GIF»: выбрать, куда сохранить готовый файл.
- «Открыть»: открыть готовый GIF в программе по умолчанию.
- «Скачать»: меню загрузки.
  · «TikTok»: вставить ссылку, выбрать место сохранения и скачать видео
    или все фото из поста. После скачивания файл сразу откроется в программе.
  · «YouTube и другие сайты»: ссылка на видео или музыку, формат MP4/MP3,
    папка сохранения.
  · «Музыка из Spotify»: ссылка на трек, альбом или плейлист; треки
    находятся на YouTube и сохраняются в MP3 или WAV.

Поле «Длительность» можно очистить — тогда будет взят весь клип
(начиная с поля «Начало»). Ширина 0 — оставить оригинальный размер.
Частота кадров по умолчанию 30; можно от 1 до 60. Число цветов фиксировано — 256.

Для картинки поля времени скрыты: программа делает GIF
из одного кадра. Ширина, палитра, сглаживание, цикл и быстрый режим
работают так же, как для видео.

Результат до сохранения лежит во временной папке и удаляется при закрытии
программы, поэтому не забудьте нажать «Сохранить GIF».

============================================================
ПЕРЕСБОРКА ИЗ ИСХОДНИКОВ
============================================================
В папке src лежат исходники на C# (WinForms, .NET Framework 4.x).
Компилятор берётся из Windows: csc.exe, отдельный SDK не нужен.

1. Положите в папку bin 64-битный ffmpeg.exe и yt-dlp.exe
   (https://github.com/yt-dlp/yt-dlp/releases/latest → yt-dlp.exe).
2. Запустите: powershell -ExecutionPolicy Bypass -File src\build.ps1

Скрипт сжимает FFmpeg в build\ffmpeg.gz, yt-dlp в build\yt-dlp.gz,
рисует иконку и собирает Jarvis.exe в корне проекта. Файлы .cs должны
быть в кодировке UTF-8 с BOM (иначе csc может испортить русский текст).

Версия без TikTok (Friday):
  powershell -ExecutionPolicy Bypass -File src\build.ps1 -NoTikTok
Собирается Friday.exe без кнопки и кода скачивания TikTok.

Сборка под старыми именами (тоже 2.4, название внутри — video2gif):
  powershell -ExecutionPolicy Bypass -File src\build.ps1 -Legacy
  powershell -ExecutionPolicy Bypass -File src\build.ps1 -Legacy -NoTikTok
Собираются Video2Gif.exe и Video2gif_notiktok.exe.

Самопроверка без графического интерфейса:
  Jarvis.exe --selftest
Результат пишется в %TEMP%\video2gif-selftest.log (проверяются FFmpeg,
yt-dlp, чтение видео и картинок, одно- и двухпроходная конвертация,
отмена, окна программы, разбор ссылок Spotify и распознавание TikTok).
